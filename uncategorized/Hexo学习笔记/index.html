Max

Overview

Node.js 是一个能让 JavaScript 语言在电脑上独立运行的环境
传统JavaScript只涉及前台，不涉及后台，当想要与服务器发生互动的时候，就需要Node.js。
Node.js自带的包管理器npm（Node Package Manager）是全球最大的开源库生态系统，有数百万个可用工具（Hexo就是其中之一）。
Hexo是一个基于Node.js的静态网站生成工具，它：

  • 使用Markdown格式编写文章

  • 通过模板引擎（如EJS、Swig）生成静态HTML文件

  • 将纯文本内容转换成完整的网站

Hexo就是一个把Markdown转换成HTML文件的工具，
下面是用hexo + github进行个人博客搭建的过程。

文章设置

当 post_asset_folder 设置为 true 时，每当你使用 hexo new <title> 创建一篇新文章时，Hexo 会自动在 source/_posts 目录下生成一个与文章同名的文件夹，用于存放该文章使用的资源文件（例如图片，更便于整理以及增减）。
![[image-6.png|446x116]]

Future和draft的区别
假设今天日期是2023年10月1日，你有一篇文章的日期设置为2023年10月10日。

如果 future: true，那么生成站点时会包括这篇文章。

如果 future: false，那么生成站点时不会包括这篇文章。

与草稿（draft）的区别

未来文章：已经写好，但日期设在未来，可以选择是否立即生成。

草稿：标记为草稿的文章，除非在生成命令中加上 --draft 参数，否则不会生成。

代码高亮

指的是在博客中插入一段代码，就像是知乎那样进行高亮显示
config.yml中syntax_highlighter下可以选择使用highlight.js或prismjs两种高亮代码库之一。highlight.js更加简单，prismjs更加专业
highlight下有几个属性：
auto_detect 是 highlight.js 的特性，能够自动检测代码块的语言。
line_number决定是否显示代码的行号
tab_replace用给定字符串替换代码块内的制表符。 默认为 2 个空格。
wrap为了支持行号显示，Hexo 将输出包裹在了 <figure> 和 <table> 内部。 如果要保持 highlight.js 原来的行为，你需要将 line_number 和 wrap 全部关闭。
这里暂时先不学prismjs的教程了，之后可以选择这个风格。

首页设置

设置 描述 默认值
index_generator 生成帖子归档。由 hexo-generator-index 驱动。
index_generator.path 博客索引页面的根路径 ''
index_generator.per_page 每页显示帖子数 10
index_generator.order_by 帖子排列顺序。 默认情况下按日期降序(从新到旧)。 -date
index_generator.pagination_dir URL 格式，请参阅下面的 分页 设置 page

分类 & 标签

设置 描述 默认值
default_category 默认分类 uncategorized
category_map 分类别名
tag_map 标签别名

日期 / 时间格式

Hexo 使用 Moment.js 来解析和显示时间。Moment.js是一个在过去十年里极为成功和流行的日期处理库

设置 描述 默认值
date_format 日期格式 YYYY-MM-DD
time_format 时间格式 HH:mm:ss
updated_option 当 Front Matter 中没有指定 updated 时 updated 的取值 mtime

分页

设置 描述 参数
per_page 每页显示的帖子数。 0 关闭分页功能 10
pagination_dir URL 格式 page

扩展

设置 描述
theme 当前主题名称。 值为false时禁用主题
theme_config 主题的配置文件。 在这里放置的配置会覆盖主题目录下的 _config.yml 中的配置
deploy 部署部分的设置
meta_generator Meta generator 标签。 值为 false 时 Hexo 不会在头部插入该标签

包括或不包括目录和文件

使用以下选项可明确处理或忽略某些文件/文件夹。 可以使用 glob 表达式 进行路径匹配。

include 和 exclude 选项只会应用到 source/ ，而 ignore 选项会应用到所有文件夹.

设置 描述
include 包含隐藏文件（包括名称以下划线开头的文件/文件夹，* 除外）
exclude 排除文件或文件夹
ignore 忽略文件/文件夹

例如用exclude：排除特定文件
用于排除 source 目录下你不希望被Hexo处理或发布的文件或目录。被排除的文件既不会被渲染，也不会被复制到 public 目录。
